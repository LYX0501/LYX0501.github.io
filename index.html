My research interests include robot manipulation and embodied navigation.

Robotic Manipulation

Scaling Manual-Grounded Appliance Manipulation with Data Synthesis and Unified Planning

Yuxing Long*, Lei Kang*, Ziyan Yu, Yuzheng Gao, Bin Cheng, Jiyao Zhang, Xiaoqi Li, Haolin Yang, Dongjiang Li, Hui Shen, Hao Dong
ACM International Conference on Multimedia (ACM MM) 2026
Paper Project Code

AppliancePlan learns to ground appliance parts, plan long-horizon tasks, and recover from disturbances using UseAppliance, a large-scale dataset synthesized from manuals through hierarchical appliance graphs.

RealAppliance: Let High-fidelity Appliance Assets Controllable and Workable as Aligned Real Manuals

Yuzheng Gao*, Yuxing Long*, Lei Kang, Yuchong Guo, Ziyan Yu, Shangqing Mao, Jiyao Zhang, Ruihai Wu, Dongjiang Li, Hui Shen, Hao Dong
Conference on Computer Vision and Pattern Recognition (CVPR) 2026 (Highlight)
Paper Project Code 机器之心

RealAppliance provides 100 realistic appliance assets with mechanical, electronic, and program behavior aligned with manuals, alongside a benchmark for grounding and manipulation planning.

CheckManual: A New Challenge and Benchmark for Manual-based Appliance Manipulation

Yuxing Long, Jiyao Zhang, Mingjie Pan, Tianshu Wu, Taewhan Kim, Hao Dong
Conference on Computer Vision and Pattern Recognition (CVPR) 2025 (Highlight)
Paper Project Code 机器之心

CheckManual introduces a benchmark for robots that consult appliance manuals to complete manipulation tasks, with simulated environments, evaluation metrics, and the ManualPlan planning baseline.

ManipLLM: Embodied Multimodal Large Language Model for Object-Centric Robotic Manipulation

Xiaoqi Li, Mingxu Zhang, Yiran Geng, Haoran Geng, Yuxing Long, Yan Shen, Renrui Zhang, Jiaming Liu, Hao Dong
Conference on Computer Vision and Pattern Recognition (CVPR) 2024
Paper Project Code

ManipLLM combines object understanding and affordance reasoning to predict manipulation contact points and end-effector poses from RGB images, with closed-loop control and real-world adaptation.

Embodied Navigation

One Scan is Enough: Demonstration-Free Adaptation for Language-Guided Navigation

Zhuoyuan Yu*, Yuxing Long*, Du Wang*, Junyang Wang, Hongwei Fan, Hao Dong
Conference on Neural Information Processing Systems (NeurIPS) 2026
Paper

One Scan is Enough turns a single iPhone scan into a training environment with synthetic instructions, enabling navigation policies to adapt to new buildings without human demonstrations.

VTInstructor: Visual Trajectory Prompting for Navigation Instruction Generation in Continuous Environments

Haolin Yang*, Yuxing Long*, Zihan Yang, Hao Dong
ACM International Conference on Multimedia (ACM MM) 2026
Paper Project Code

VTInstructor converts RGB navigation videos into explicit visual trajectory prompts, generating grounded instructions in continuous environments without navigation graphs or pre-built maps.

NavSpace: How Navigation Agents Follow Spatial Intelligence Instructions

Haolin Yang*, Yuxing Long*, Zhuoyuan Yu, Zihan Yang, Minghan Wang, Jiapeng Xu, Yihan Wang, Ziyan Yu, Wenzhe Cai, Lei Kang, Hao Dong
International Conference on Robotics and Automation (ICRA) 2026
Paper Project Code 北京日报

NavSpace evaluates navigation agents on six types of spatial instructions and introduces SNav, a model trained to follow these instructions in simulation and on real robots.

CorrectNav: Self-Correction Flywheel Empowers Vision-Language-Action Navigation Model

Zhuoyuan Yu*, Yuxing Long*, Zihan Yang, Chengyan Zeng, Hongwei Fan, Jiyao Zhang, Hao Dong
AAAI Conference on Artificial Intelligence 2026
Paper Project Code

CorrectNav learns from its own navigation failures by repeatedly generating self-correction data, improving error recovery and instruction following through an iterative post-training process.

InstructNav: Zero-shot System for Generic Instruction Navigation in Unexplored Environment

Yuxing Long*, Wenzhe Cai*, Hongcheng Wang, Guanqi Zhan, Hao Dong
Conference on Robot Learning (CoRL) 2024
Paper Project Code 量子位

InstructNav combines dynamic navigation reasoning with multi-sourced value maps to follow diverse instructions in unexplored environments, without navigation training or pre-built maps.

Discuss Before Moving: Visual Language Navigation via Multi-expert Discussions

Yuxing Long, Xiaoqi Li, Wenzhe Cai, Hao Dong
International Conference on Robotics and Automation (ICRA) 2024
Paper Project Code 量子位

DiscussNav consults specialized large models for instruction understanding, scene perception, and progress estimation before each move, enabling zero-shot navigation through multi-expert reasoning.

Bridging Zero-Shot Object Navigation and Foundation Models through Pixel-Guided Navigation Skill

Wenzhe Cai, Siyuan Huang, Guangran Cheng, Yuxing Long, Peng Gao, Changyin Sun, Hao Dong
International Conference on Robotics and Automation (ICRA) 2024
Paper Project Code

PixNav connects foundation models to robot movement through an RGB navigation policy guided by target pixels, supporting zero-shot object navigation with language-model planning.
